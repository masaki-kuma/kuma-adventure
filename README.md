# くまちゃん大冒険（仮） 🐻🎮

第1作「くまちゃんとおやつの部屋」v0.2。部屋で3つのおやつを見つけて脱出するブラウザゲームです。

## 遊び方
- PC：方向キー / WASDで移動、Space / Enter / Eで調べる
- iPhone：画面内の方向ボタンと「しらべる」ボタンを使用
- 3個のおやつを見つけたら扉へ

## 公開方法（GitHub Pages）
1. GitHubで `kuma-adventure` という **Public** リポジトリを作成
2. この `index.html` と `README.md` をリポジトリ直下に配置
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save
4. 公開後 `https://masaki-kuma.github.io/kuma-adventure/` で遊べます（Pages有効化が必要）

## 備考
ゲーム素材はHTML内に埋め込まれているため、現時点では `index.html` 単体で動作します。
