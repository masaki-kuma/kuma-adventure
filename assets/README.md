# 3×3パズル画像素材の基準（Issue #3）

## 正式なデザイン
ユーザーが採用した **「くまちゃん大冒険（仮）／ミニゲーム／3×3パズル」の画面**が唯一の基準です。左に3匹のくまちゃん、中央に3×3の盤面、右に特製おやつ、背景はハロウィン村、金色の飾り枠があります。

## 登録予定の画像（まだ未登録のものを含みます）
- `puzzle_ui_reference.png`: 正式な画面見本そのまま
- `puzzle_picture.png`: 正式見本の中央の9つのタイル内部から抽出した盤面画像
- `puzzle_backdrop.jpg`: 同じ見本を加工した背景
- `three_bears_panel.png`: 同じ見本左の3匹の画像
- `reward_panel.png`: 同じ見本右のおやつ画像
- 同等のWebP軽量版

素材の正本は会話内で作成した `くまちゃん大冒険_お気に入り画像から切り出した素材_改訂版.zip` です。ファイルの存在はリポジトリに実際にアップロードされた後で確認してください。**READMEだけあっても画像を登録したことにはなりません。**

## 旧指示からの変更
以前の別々に再構成された背景・完成絵は採用しません。承認画像**そのもの**から切り出した絵を使って、見た目を統一します。

元の生成画像の中央タイルは厳密にシームレスな一枚絵ではないため、抽出した各タイルにも絵の不連続があります。必要なら将来のアート改善として分離してください。

既存PR #2の交換操作・クリア判定・おやつ付与・iPhoneタッチ操作は変更しません。

詳しい受入条件は Issue #3 を参照。
