# 3×3パズル画像素材の登録・利用について

Issue #3 のビジュアル改修用アセット一覧です。元になるチャット生成画像から、以下の素材の切り出し・軽量化を実施しています。

| ファイル | 用途 | 備考 |
|---|---|---|
| `assets/puzzle_picture.png` | 3×3に分割する1枚の絵 | 正方形432×432 |
| `assets/halloween_background.jpg` | ハロウィン村の背景 | 640×480 |
| `assets/three_bears.png` | 仲間3匹の装飾 | 左側に配置 |
| `assets/special_snacks.png` | ごほうびのおやつ | 右側に配置 |
| `assets/design_reference.png` | 目標レイアウトの見本 | パズル盤には使わない |

**重要**：このREADMEは素材の仕様であり、画像ファイルそのものではありません。画像がリポジトリに配置されたら、本ファイルと同じ`assets/`フォルダ内に保存してください。画像が揃う前に、ダミー画像で仕上げたPRを完成扱いにしないでください。

既存PR #2の入れ替え操作、クリア判定、報酬1回、宝箱の進行、iPhoneのタッチ操作は維持してください。

デザインの目的は、紫の夜空、紅葉、月、街並み、3匹のくまちゃん、金色のフレーム、「3×3パズル」「ごほうび」表示の再現です。

元画像は会話内で生成されたもの。素材切り出し時に日本語のラベルが残っていないか、パズル盤面上で確認してから採用してください。
